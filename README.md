# BLG INDUSTRY — Mini App (prototype)

## Contenu
- `index.html` : interface de la Mini App
- `styles.css` : design responsive rouge/noir
- `app.js` : catalogue de démonstration et panier local
- `assets/assets/blg-logo.jpeg` : visuel fourni

## Mise en ligne
Publiez le contenu de ce dossier sur un hébergement statique HTTPS (par exemple GitHub Pages, Cloudflare Pages ou Netlify), puis configurez l'URL publique dans BotFather pour le bot `@blgindustrybot`.

## Important avant toute mise en vente
Cette version est une maquette fonctionnelle d'interface, pas une boutique transactionnelle. Les produits et prix sont des placeholders. Ne branchez pas de paiement et n'acceptez pas de commandes avant d'avoir vérifié la conformité des produits (notamment THC), les règles françaises applicables, les obligations d'information/âge, les conditions du prestataire de paiement et les règles Telegram. Le panier est uniquement local et ne transmet aucune commande.

Ne placez jamais le token du bot dans les fichiers front-end. Toute logique nécessitant un secret doit être exécutée côté serveur.
